# Room Dashboard

A fun little project I built for a dedicated screen in my room.

The idea was to have a clean, ambient display running throughout the day that gives me a quick look at daily essentials without having to pick up my phone or open a bunch of apps. It brings together things like the time, local weather, what is on my schedule, tasks for the day, Bangalore traffic map, flights over my head and other quick updates I like keeping an eye on.
